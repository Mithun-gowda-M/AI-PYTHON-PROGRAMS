# AI Python Programs

Standalone Python implementations for the core experiments in the Artificial Intelligence Laboratory Manual (2026–27, 1BAI302). Each program includes a runnable example and uses only the Python standard library.

## Programs

| File | Experiment |
|---|---|
| `01_bfs_food_delivery.py` | Breadth First Search for a shortest route in an unweighted city road network |
| `02_dfs_sudoku_solver.py` | Sudoku solver using Depth First Search and backtracking |
| `03_astar_warehouse.py` | A* path planning through a warehouse grid with obstacles |
| `04_eight_queens.py` | Eight Queens using backtracking |
| `05_nearest_neighbor_route.py` | Delivery route construction using the Nearest Neighbor heuristic |
| `06_forward_chaining_diagnosis.py` | Forward chaining over a small educational symptom rule base |
| `07_first_order_resolution.py` | First-order clause resolution with unification, proving a loan eligibility query |
| `08_automobile_expert_system.py` | Rule-based automobile fault diagnosis and suggested actions |

## Run

Use Python 3.10 or newer. Run a program from this directory, for example:

```bash
python 01_bfs_food_delivery.py
```

The medical diagnosis and automobile examples are educational demonstrations, not professional advice. Part B of the manual lists open-ended project prompts rather than complete, specified programs; these eight files cover the eight defined Part A experiments.
